# Art / Audio / Level Designer

who: 

You own how the game looks, sounds, and is laid out. You help create the world the player actually experiences.

## What you'll do
- Choose an art style
- Create or find sprites and tilesets
- Design and build levels
- Create the level for the midway demo
- Add sound effects
- Add music

## Timeline
- Weeks 1-2: Choose the game's visual style and collect free assets. Good places to look: itch.io, OpenGameArt, Kenney.nl
- Weeks 2-3: Provide placeholder sprites and a usable tileset the programmers can start working with right away.
- Midway checkpoint: Have one playable level layout ready for the demo.
- Weeks 4-5: Expand the game with more levels, final art, sound effects, and music.

## Tips
- Placeholders first, polish later. Programmers need assets early so they can build and test the game.
- Useful tools: Aseprite, Piskel, BFXR, and free music libraries
- Always check the license before using an asset in the project!
