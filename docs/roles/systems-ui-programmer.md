# Systems / UI Programmer

who: 

You own everything around the gameplay that makes the project feel like a complete game.

## What you'll do
- Build the main menu
- Create the pause screen
- Add score and health displays
- Handle level loading
- Create win and lose screens
- Handle save data if needed
- Export the final playable build

## Timeline
- Weeks 1-3: Learn the engine's UI tools and coordinate with the gameplay programmer on how things like health and score will be shared.
- Midway checkpoint: Have a simple start screen and at least one working gameplay display, such as score or health.
- Weeks 4-5: Polish menus and connect the different parts of the game.
- Final weeks: Test exported builds on different computers and make sure everything works outside the development environment.

## Tips
- Keep the UI simple and readable. Clear beats pretty.
- Test exporting the game early.
- Don't wait until the final week to discover the build doesn't work!
